A. O que é uma View no Android Framework?
R: É a classe básica que é pai de todos os componentes visuais da IDE, Buttons, TextViews.

B. O que é um ViewGroup no contexto da interface do Android?
R: É um container que possue todos os componentes que apareceram na tela, básicamente é o componente que possui tudo que aparece na tela.

C. Qual é a função dos LayoutParams dentro de um ViewGroup?
R: Como diz o nome, são os parâmetros do Layout, que controlam como um componente vai se comportar dentro do grupo, posicionamento e tamanho.

D. Por que diferentes ViewGroups (como LinearLayout, ConstraintLayout, FrameLayout) utilizam subclasses específicas de LayoutParams?
R: Porque cada ViewGroup organiza os componenetes de uma forma diferente, cada um segue sua própria regra.
